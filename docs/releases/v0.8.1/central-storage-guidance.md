# v0.8.1 中心存储目录提示修复

## 问题

用户将 Skill 文件夹直接放入 Skills Hub 的中心存储目录后，再从“添加 Skills → 本地目录”选择该文件夹，会收到“已存在于 Hub，可前往‘我的 Skills’中更新”的提示，但该 Skill 实际上没有数据库记录，也不会显示在“我的 Skills”中。

## 产品边界

中心存储目录由 Skills Hub 自动管理。新增 Skill 必须通过本地目录或 Git 仓库导入，由应用完成复制、登记和同步；直接复制文件夹到中心目录不等同于安装或托管。

## 修复

保留现有的安全策略，不自动接管或覆盖中心目录中的未知文件夹。错误提示改为说明中心目录的托管属性，并指引用户先将 Skill 移到其他目录，再通过“本地目录”重新添加。

中英文提示保持相同语义。

## 验收

1. 在中心存储目录中放入一个包含合法 `SKILL.md`、但没有数据库记录的测试目录。
2. 从“添加 Skills → 本地目录”选择该目录并创建。
3. 应用阻止导入，且提示中心目录由 Skills Hub 自动管理。
4. 提示应引导用户把 Skill 移到其他目录后重新添加，不再声称它已存在于“我的 Skills”。
5. `npm run version:check` 和 `npm run check` 均通过。
