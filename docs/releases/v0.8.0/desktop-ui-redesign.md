# 桌面端 UI 重构

## 背景

v0.7.x 的功能逐步增加后，不同页面形成了各自的布局与交互方式。在默认窗口之外的尺寸中，部分列表和表单无法完整滚动；首页表格在窄窗口中容易挤压；在线探索、安装配置、工具管理和更新页面的信息密度也不一致。

v0.8.0 保持既有 Skills 管理、同步和 Tauri IPC 行为兼容，通过统一的桌面端设计体系重新组织现有功能，并在此基础上扩展自定义工具配置和迁移能力。

## 设计原则

- 优先保证常见桌面窗口尺寸下的完整可用性。
- 同一层级使用一致的间距、边框、圆角、状态色和交互反馈。
- 操作区保持稳定，内容区域独立滚动。
- 根据可用空间调整布局，不依赖超大默认窗口隐藏问题。
- 图标用于增强识别，不能替代必要的文本和状态提示。
- 浅色、深色、中英文和长文本使用相同的响应式规则。

## 首页与导航

- 首页统计、搜索、范围筛选、排序、标签筛选和批量管理重新排列为稳定的工具区。
- Skills 支持列表和卡片两种视图，并提供明确的切换按钮。
- 卡片列数根据内容区宽度自动变化；只剩一个筛选结果时保持标准列宽，不再横向撑满内容区。列表视图为描述、标签、范围、同步工具和操作保留稳定空间。
- Skill 来源通过文件夹或 Git 图标区分，路径位置改为更有信息价值的描述，并保留复制能力。
- 侧边栏可折叠为图标导航；折叠按钮、分组边界和悬浮提示保持一致。

## 工具展示

- 工具列表和 Skill 同步状态使用对应产品 Logo，减少文字缩写带来的识别成本。
- 工具开关关闭后仍保留在管理页面，用户可以随时重新启用。
- 自定义工具支持配置头像，并在工具管理、安装流程和 Skill 同步状态中使用同一身份展示。
- 自定义工具卡片将启停开关保留在右上角，将编辑和删除移动到带分隔线的底部操作区，区分即时状态与管理操作。
- 安装配置中的工具使用紧凑胶囊布局：工具较少时自然收紧，工具较多时自动换行。
- 不支持当前安装范围的工具保持可见但不可选，并显示相应提示。

## 在线探索与安装流程

- 在线探索、Git 仓库和本地目录使用一致的顶部页签与间距，切换时页面不会跳动。
- 在线探索卡片重新调整宽度、描述截断和按钮位置，减少两侧无效留白。
- Git 与本地安装页面使用连续表单，按“来源、标签、工具、范围”组织配置，不再折叠关键选项。
- 标签和工具数量较多时只滚动对应内容区域，不推动底部操作栏离开窗口。
- 安装摘要、取消和安装按钮固定在底部，并保持一致尺寸与对齐方式。
- 多 Skill 检测结果使用独立可滚动选择弹窗，搜索、全选、计数和操作按钮保持可见。

## 管理与设置页面

- 标签、工具、更新和设置页面统一卡片宽度、内容密度与滚动边界。
- 工具管理在不同数量下保持合理排列，自定义工具表单与已配置工具分区明确。
- 已创建的自定义工具可以回填到原表单中编辑名称、头像、目录和同步模式；保存期间禁用重复操作，并在失败后恢复有效配置。
- 更新页面重新分配左右空间，使运行结果和失败信息不再集中挤压在窄列。
- 设置页面的表单、说明和开关使用稳定列宽，避免长文案挤压操作控件。
- GitHub 开源项目入口位于设置页“GitHub 与网络”区域，通过系统默认浏览器打开；Tauri 权限仅允许打开项目仓库地址。

## Tauri 窗口体验

- 默认窗口调整为更适合桌面应用的尺寸，并设置可用的最小宽高。
- 顶部标题区域支持窗口拖动，同时排除按钮等交互控件。
- 增加窗口四边与四角缩放区域，改善无原生边框模式下的窗口调整体验。
- macOS 交通灯位置与应用标题栏对齐。
- 标题栏版本区域在启动时执行非阻塞更新检查；发现新版本后显示更新图标，点击后打开包含更新说明和安装操作的弹窗。
- 更新检查不再自动弹出窗口，避免启动时打断当前操作；安装完成后继续提示重启应用。

## 启动反馈

- 首次启动仍会扫描可导入的 Skills，但改为后台静默执行，不再显示“正在安装技能”的全屏遮罩。
- 用户主动执行安装、同步、删除或导入扫描时继续使用明确的加载反馈和取消入口。

## 主题与国际化

- 颜色、背景、边框和状态色统一通过主题变量提供浅色与深色版本。
- 新增界面文本同时提供中文和英文翻译。
- 长路径、长描述、工具名称和英文标签使用截断或换行规则，避免破坏布局。
