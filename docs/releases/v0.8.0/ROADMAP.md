# v0.8.0 Roadmap

## 版本定位

v0.8.0 是 Skills Hub 的桌面端界面重构版本，重点解决 v0.7.x 在常见桌面窗口尺寸下信息密度不均、页面滚动不完整、安装流程层级混乱以及不同页面视觉规范不一致的问题，并补充自定义工具编辑、同步策略和应用更新状态入口。

本版本保持既有 Skills 管理逻辑、Tauri IPC 和真实数据链路兼容，集中重构布局、样式、窗口交互和响应式行为，并在原有自定义工具模型上扩展身份、同步策略和安全迁移能力，使 Skills 的浏览、筛选、安装、同步和管理流程更加紧凑、稳定且易于理解。

## 版本目标

- 统一首页、在线探索、标签、工具、更新和设置页面的布局与视觉规范。
- 首页支持列表和卡片两种视图，并根据可用宽度自适应卡片列数。
- 侧边栏支持折叠为纯图标导航，为内容区释放更多空间。
- 使用真实工具 Logo 替代难以识别的文字缩写。
- 重构 Git 与本地安装流程，保持标签、工具和范围配置清晰可见。
- 修复列表、弹窗和配置页面在较小窗口中无法完整滚动或操作的问题。
- 改善 Tauri 桌面窗口的拖动与边缘缩放体验。
- 支持为自定义工具配置头像和明确的同步模式，并在修改配置时迁移已有同步目标。
- 将应用版本、更新检测和开源项目入口分配到符合信息层级的位置。
- 保持浅色、深色以及中英文界面的完整适配。

## 验收标准

- 常见桌面窗口尺寸下，各主要页面内容完整可见并可滚动。
- 首页可以在列表和卡片视图之间切换，选择结果在视图切换后保持一致。
- 卡片视图根据内容区宽度自动调整列数，不产生不必要的大面积留白。
- 卡片视图只剩一个 Skill 时保持标准列宽，不横向撑满整个内容区。
- 侧边栏折叠后仅显示图标，导航、提示和设置入口仍可正常使用。
- 标签筛选、范围筛选、排序和批量管理入口完整保留。
- Git 与本地安装页面的标签、工具和范围配置无需折叠即可完成操作。
- 安装页底部摘要与操作按钮始终可见，内容过多时由内容区域滚动。
- 工具启停不会导致工具入口消失，已支持工具使用正确 Logo 展示。
- 自定义工具支持头像、自动/软链接/目录联接/复制模式和创建后编辑。
- 修改自定义工具目录或同步模式后，已有非禁用目标安全迁移，共享目标不被误删或改写。
- 自定义工具卡片右上角只保留启停开关，编辑和删除位于独立的底部操作区。
- 顶部空白区域可拖动窗口，窗口边缘可执行缩放。
- 启动时静默扫描可导入 Skills，不显示与实际操作不符的安装遮罩。
- 标题栏检查应用更新；发现新版本时显示可访问的更新入口，GitHub 项目入口位于设置页。
- 中英文和浅色/深色主题下布局与交互保持一致。
- 应用版本号统一为 `0.8.0`，前端和 Rust 全量检查通过。

## 设计原型

v0.8.0 Beta 窗口与桌面端 UI 设计资产统一存放在 [`prototypes/`](prototypes/)：

- [`ui-prototype.html`](prototypes/ui-prototype.html)：桌面端 UI 重构交互原型。
- [`figma-handoff.html`](prototypes/figma-handoff.html)：Figma 单文件交接画布。
- 同目录下的 `*.artifact.json` 为对应 HTML 原型的渲染与导出配置。

## 验证

实现完成后运行：

```bash
npm run version:check
npm run check
```

验证覆盖版本一致性、ESLint、前端测试、TypeScript/Vite 构建、Rust 格式、Clippy 和 Rust 测试。当前结果为前端测试 31 项、Rust 测试 131 项通过。
